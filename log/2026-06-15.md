## Decisions made

- **Coach is session-bound by design** — no pasted labels from outside the current session. Integrity of coaching depends on having witnessed the work.
- **Three-state coaching model** — State 1 (at/near baseline): affirm. State 2 (below baseline, recoverable): 3 questions, "I'll wait." State 3 (< 30%): input playbook, "Don't turn it in yet."
- **Module seam format for compiled prompt** — `<!-- MODULE: name v# -->` markers make the compiled file machine-splittable for future V2 recompile.
- **Supersede, don't delete** — old prompts moved to `superseded/` with a README. History preserved, clutter gone.
- **`~/github/` as single repo home** — all active PL repos consolidated; Documents copies retired.
